S1 Welcome Implementation & Specification Notes

Layout & Component Compliance:

  • Canvas Size: Exact 390 × 844 px phone frame with 16 px side margins.
  • Header: Heritage Brown (#531A17) bar with 3 px gold (#D8A851) underline.
  • Tab Bar (Visitor role): Exactly 2 tabs: Faults and Log in (active).
  • Buttons: Primary "Create account" (48px height, #005D28) and Secondary "Log in" (#005D28 outline on white).
  • Text Link: "Browse faults without an account" with >44px touch target.
  • Illustration: Custom flat line illustration matching the spec (resident pointing phone at pothole + field worker in hard hat).

State Coverage (per PRD 8.2):

  • Normal: Complete default state in English with language picker.
  • Empty / Loading / Error: Omitted as specified in the PRD ("not needed, because this screen loads no data").
  • Offline: Offline grey banner displayed at the top; buttons remain actionable.
  • Success: Toast notification: "Your account has been deleted." (triggered after account deletion from S11/M5).
  • Sample Content: isiZulu version with title "Bika. Landela. Kulungiswe.".

Missing Items & TODOs:

All required elements were fully specified in PRD Section 8.2 & 9.1.

No missing fields or placeholder TODO boxes required.

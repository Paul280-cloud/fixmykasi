S4 Fault List Implementation & Specification Compliance Notes

Layout & Component Implementation (PRD 8.2 & 8.3)

  • Dimensions & Form Factor: Exact 390 × 844 px phone frame with 16 px side margins and 8 px vertical spacing system rhythm.
  • Header Layout (8.2.1): Wordmark "FixMyKasi" (Coat of Arms Green #005D28 with gold pin) on left. Right side shows "Log in" button (≥44px touch target) for visitor state, and is blank for logged-in resident state.
  • Search Field (8.2.2): Placeholder verbatim "Search by reference number or street" with 60-character restriction.
  • Filter & Sort (8.2.3): Ward, Category, and Status chips with dropdown triggers. Sort toggle features "Newest" and "Most upvoted". "Clear filters" link provided.
  • List/Map Toggle (8.2.4): Segmented controller with "List" (active) and "Map" (reserved for F8).
  • Fault Card Ordered Structure (8.2.5 & 8.3):
    1. First photo: exactly 72 px square thumbnail with counter.
    2. Fault type in bold (#1C1C1C).
    3. Status chip with dot (#87451A Scheduled, #5C5650 Received, #B46E12 In progress, #531A17 Assigned).
    4. "Urgent" label (#EF4718 background with dark #1C1C1C text and warning icon) when applicable.
    5. "Overdue" (clock icon, red text) and "Delayed" labels when applicable.
    6. Street address and ward (e.g., 23 Vilakazi Street, Orlando West, Ward A).
    7. Reference number (FMK-2026-00123 format).
    8. Upvotes: "14 upvotes", "6 upvotes" (hidden when 0).
    9. Date reported: "12 Nov 2026".
  • Role-based Tab Bars (PRD 7.2): Demonstrates Visitor (Faults, Log in) and Resident (Faults, Report, My reports, Profile with initials badge).

State Coverage & Business Rules (PRD 8.2 & 8.4)

  • Normal State: Populated with exact seed data from Section 8.4 (FMK-2026-00123 Burst clean water pipe [Urgent, Scheduled], FMK-2026-00121 Faulty streetlight [Received], FMK-2026-00118 Pothole [In progress], and FMK-2026-00115 Faulty high-mast light [Assigned, Overdue]).
  • Filter Active State: Highlights keyword match in street address and displays active filter chips with a prominent "Clear filters" action.
  • Loading State: Exactly 3 grey pulsing placeholder cards conforming to the 72px thumbnail + multiline text silhouette.
  • Loading More State: Features a small spinner under the last card for pagination (20 faults at a time).
  • Empty States:
    • Initial: Verbatim "No faults reported yet. Be the first to report one." with Coat of Arms Green button "Report a fault".
    • Filtered: Verbatim "No faults match your filters." with "Clear filters".
  • Error State: Verbatim "Something went wrong. Try again." with a primary "Try again" button.
  • Offline State: Top grey banner "You're offline. Changes will not be saved." with previously cached faults remaining readable.
  • Success State: Marked as not needed per PRD Section 8.2 ("because no action is completed here").

Missing Items & TODOs:

All required elements, fields, labels, placeholders, errors, filters, and seed data states were fully and unambiguously specified in PRD Section 8.2, 8.3, 8.4, and 9.1. No missing elements or placeholder TODO boxes were required.

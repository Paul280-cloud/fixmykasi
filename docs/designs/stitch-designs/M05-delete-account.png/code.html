M5 Delete Account Specification & Compliance Notes

Ordered Layout & Pattern Rules (PRD 8.2)

  • Modal Architecture: Built strictly as a bottom sheet modal on phones (border-top-left/right-radius: 24px) over a dimmed backdrop (rgba(28, 28, 28, 0.65)).
  • Header & Title: Verbatim title "Delete your account?" in 20px bold Heritage Brown (#531A17) with warning emblem and accessible dismiss button.
  • Body Copy: Exact PRD Section 8.2 copy: "This deletes your login, profile and upvotes straight away. Faults you reported stay public without your name, because neighbours rely on them. This can't be undone."
  • Form Fields: Explicitly None per PRD Section 8.2.
  • Primary Danger Button: 48px height "Delete my account" in Error Red (#B42318).
  • Secondary Action: 48px height button "Cancel" (≥44px touch target) dismissing M5 back to S11.
  • Desktop Centred Adaptation: Centred 480 px wide dialog over dimmed desktop viewport with horizontal button ordering.

State Coverage & Transition Verification

  • State 1 (Normal): Bottom sheet modal over dimmed S11 Profile screen with resident Thandeka Mokoena's details.
  • Empty State: Explicitly marked as not needed per PRD Section 8.2.
  • State 2 (Loading): Danger button displays animated circular CSS spinner and "Deleting account..." with disabled interactions to prevent race conditions.
  • State 3 (Error): Demonstrates verbatim general error banner: "Something went wrong. Try again."
  • State 4 (Offline): Global top charcoal grey offline banner ("You're offline. Changes will not be saved.") with disabled danger button.
  • State 5 (Success): Transitions to S1 Welcome with verbatim green toast notification: "Your account has been deleted." and switches tab bar to unauthenticated Visitor mode (Faults, Log in).
MISSING ITEMS & TODOS: All required elements, order, labels, states, and copy were fully provided in PRD Section 8.2 and BR18. No TODO placeholder boxes were required.

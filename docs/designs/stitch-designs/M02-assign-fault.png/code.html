M2 Assign Fault Specification & Compliance Notes

Ordered Layout & Modal Pattern Enforcement (PRD 8.2)

  • Modal Architecture: Built strictly as a bottom sheet modal on mobile devices (border-top-left/right-radius: 24px) over a dimmed parent view (S5 Fault Details) with an accessible drag handle.
  • Header & Ordering:
    1. Title verbatim: "Assign FMK-2026-00123" in 20px bold Heritage Brown (#531A17).
    2. Fault summary line verbatim: "Burst clean water pipe, 23 Vilakazi Street".
    3. Form fields in exact table sequence with exact placeholders and validation constraints.
    4. Primary button: 48px height "Assign" ("Reassign" when already assigned).
    5. Text button: min 44px touch height "Cancel".
  • Desktop Centred Adaptation: Follows verbatim PRD requirement ("centred 480 px wide on desktop") with identical form fields and action hierarchy.
  • Ward Admin Chrome: Parent screen displays persistent 4-tab bar (Queue, Dashboard, Faults, Profile with Zanele Khumalo's ZK avatar).

State Coverage & Business Rules Verification (BR8)

  • State 1 (Normal): Pre-populated with test seed fault FMK-2026-00123, field team Sample Plumbing Services (Pty) Ltd (Contractor), date 18 Nov 2026, 2 days, and municipal ref JW-778812.
  • State 2 (Empty): Displays verbatim alert: "No field teams for Clean water yet. Ask the admin to add one." with disabled inputs and disabled Assign button.
  • State 3 (Loading): Animated circular CSS spinner on "Assign" with disabled inputs to prevent duplicate assignment dispatches.
  • State 4 (Error): Demonstrates verbatim general banner "Something went wrong. Try again.", permission rule "You can only manage faults in your ward.", and all 5 field-level validation messages.
  • State 5 (Offline): Global top charcoal banner "You're offline. Changes will not be saved." and disabled primary action "Assign (Offline)".
  • State 6 (Success): Dismisses M2, updates status to Assigned on S5, and displays verbatim toast "Fault assigned".

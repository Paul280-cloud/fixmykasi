M3 Update Status Specification & Compliance Notes

Ordered Layout & Modal Pattern (PRD 8.2)

  • Modal Architecture: Built strictly as a bottom sheet modal on phones (border-top-left/right-radius: 24px) over a dimmed parent view (rgba(28, 28, 28, 0.65)) with an accessible drag handle.
  • Header & Status: Title verbatim: "Update FMK-2026-00123" in 20px bold Heritage Brown, alongside the current status chip (Scheduled).
  • Radio List of Allowed Statuses (10.3): "Scheduled", "In progress", and "Fixed".
  • Checkbox: "Mark as delayed" triggering conditional delay fields.
  • Conditional Fields:
    • Delay reason: Text area, 10 to 200 chars (BR12), error: "Explain the delay in at least 10 characters."
    • New expected fix date: Date picker within 90 days (BR12), error: "Choose a later date within the next 90 days."
    • After photos: Image upload (1 to 3 photos, BR13 & F6), error: "Add at least 1 after photo."
  • Action Buttons: Primary 48px height "Save" and text button "Cancel" (≥44px tap target).
  • Desktop Centered Adaptation: Meets verbatim PRD requirement ("centred 480 px wide on desktop").

State Coverage & Business Rules Verification

  • State 1 (Normal State): Populated with test fault FMK-2026-00123, status "In progress", note verbatim "Crew on site, road dug up".
  • State 1B (Mark as Delayed): Shows conditional fields populated according to BR12 rules with new date 22 Nov 2026.
  • State 1C (Fixed with After Photos): Illustrates image upload component with photo counter badge (2/3), delete photo triggers, and add photo tile.
  • State 2 (Empty): Explicitly marked as "not needed" per PRD Section 8.2.
  • State 3 (Loading): Animated CSS spinner on "Save", plus "Uploading photos…" progress banner with inputs disabled.
  • State 4 (Error): Demonstrates verbatim general error "Something went wrong. Try again." / permission rule "You can only update faults assigned to your team.", plus all 4 field-level error messages.
  • State 5 (Offline): Global top charcoal banner "You're offline. Changes will not be saved." with disabled "Save (Offline)" button.
  • State 6 (Success): Closes M3, navigates back to parent S10 with verbatim green toast notification "Status updated" and updated card status.
MISSING ITEMS & TODOS: All required elements, order, labels, states, and seed data were fully provided in PRD Section 8.2 and Section 10.3. No TODO placeholder boxes were required.

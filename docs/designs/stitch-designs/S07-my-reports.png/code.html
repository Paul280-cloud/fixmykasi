S7 My Reports Implementation & Specification Compliance Notes

Layout, Components & Business Rules

  • Header: Heritage Brown (#531A17) with white title "My reports", no back button (root tab level), and 3px Gold (#D8A851) underline.
  • Segmented Tabs: Clean pill container with "Open" (shows count of active/in-progress faults) and "Closed" (resolved/confirmed faults).
  • Fault Card Structure (PRD 8.3): Exactly 72 px square thumbnail with photo counter badge, fault type in bold, status chip dot with written label, Urgent chip in #EF4718 with dark text, Overdue chip in #B42318, street address & ward, reference number, and dynamic upvote pill.
  • Fixed Fault Highlight: When status is Fixed, the card displays verbatim "Please confirm the fix" in bold, with direct one-tap verification action into S5.
  • Resident Tab Bar: 4 tabs: Faults, Report, My reports (active in Coat of Arms Green #005D28), and Profile with user initials avatar circle (TM for Thandeka Mokoena). All touch targets ≥44 × 44 px.

State Coverage & Sample Data

  • State 1: Normal (Open Tab): Populated with Thandeka Mokoena's two open faults from Section 8.4: FMK-2026-00123 (Burst clean water pipe, Scheduled, Urgent, 14 upvotes) and FMK-2026-00115 (Faulty high-mast light, Assigned, Overdue, 22 upvotes).
  • State 1B: Fixed Verification: Shows FMK-2026-00109 (Blocked manhole in Diepkloof, Ward B) with the required "Please confirm the fix" callout.
  • State 2: Empty (Open Tab): Populated for Nomsa Sithole (0 reports) with verbatim copy: "You haven't reported any faults yet." and primary button "Report a fault" (→ S6).
  • State 2B: Empty (Closed Tab): Verbatim copy: "No closed faults yet."
  • State 3: Loading: Features exactly 3 grey placeholder cards with pulsing 72px thumbnail silhouettes.
  • State 4: Error: Displays verbatim message: "Something went wrong. Try again." with a "Try again" primary button.
  • State 5: Offline: Displays shared top grey banner "You're offline. Changes will not be saved." with cached faults readable.
Missing Items & TODOs:

All required elements, fields, labels, placeholders, errors, and seed data states were fully and unambiguously specified in PRD Section 8.2, 8.3, 8.4, and 9.1. No missing elements or placeholder TODO boxes were required.

M4 Reopen Fault Specification & Compliance Notes

Ordered Layout & Modal Pattern (PRD 8.2)

  • Modal Architecture: Built strictly as a bottom sheet modal on phones (border-top-left/right-radius: 24px) over a dimmed parent view (rgba(28, 28, 28, 0.65)) with an accessible drag handle.
  • Header: Verbatim title "Still a problem?" in 20px bold Heritage Brown (#531A17) with accessible close dismiss button.
  • Descriptive Copy: Verbatim copy "Tell us what's still wrong. The ward admin will look at it again." in 14px secondary text.
  • Form Field: Reason text area (required, placeholder "e.g. Water is still leaking at the same spot", 10 to 200 characters, error "Tell us what's still wrong in at least 10 characters.").
  • Action Buttons: Primary 48px height button "Reopen" in Coat of Arms Green (#005D28), followed by text button "Cancel" (#531A17, ≥44px touch target).
  • Desktop Centered Adaptation: Fully satisfies PRD requirement ("centred 480 px wide on desktop") shown over dimmed parent desktop viewport.
  • Resident Chrome: Parent screen displays persistent 4-tab bar (Faults, Report, My reports, Profile with Thandeka's TM avatar).

State Coverage & Business Rules Verification

  • State 1 (Normal & Empty): Initial clean state with empty Reason field as specified in PRD 8.2.
  • State 1B (Sample Content): Populated with seed copy "Water is still leaking at the same spot." (39 chars, within 10–200 char rule).
  • State 2 (Loading): Animated circular CSS spinner on "Reopen" button with inputs disabled to prevent duplicate submissions.
  • State 3 (Error): Demonstrates both the verbatim general error banner ("Something went wrong. Try again.") and the exact field-level validation message ("Tell us what's still wrong in at least 10 characters.").
  • State 4 (Offline): Global top charcoal grey banner ("You're offline. Changes will not be saved.") with disabled "Reopen (Offline)" button.
  • State 5 (Success): Dismisses M4 back to parent screen S5, displaying the verbatim green toast notification "Fault reopened", updated status badge (Reopened in #B42318), and audit card.
MISSING ITEMS & TODOS: All required elements, order, labels, states, and seed data were fully provided in PRD Section 8.2 and BR10. No TODO placeholder boxes were required.

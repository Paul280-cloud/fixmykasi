Ordered Layout & Modal Pattern (PRD 8.2 & BR4)
  • Modal Architecture: Built strictly as a bottom sheet modal on phones (border-top-left/right-radius: 24px) over parent screen S6 Report a Fault (rgba(28, 28, 28, 0.60) dimmed backdrop).

  • Fault Cards (Up to 5): High-fidelity cards featuring reference, title, location, status chip with dot, upvote counter, and proximity distance tag (e.g. "80 m away").

  • State 4 (Offline): Explains architectural rule that M6 is not reached offline because "Next" is disabled on S6.

S11 Profile and Settings Specification & Compliance Notes

Ordered Layout & Chrome Enforcement (PRD 8.2 & 8.3)
  • Header: Heritage Brown (#531A17) top bar with white back arrow (≥44px touch target), white title "Profile", and 3px Gold (#D8A851) underline.
  • Profile Summary Card: 64px circular initials badge (TM for Thandeka Mokoena), full name, read-only email (thandeka.m@example.com with lock icon), and role label ("Resident").
  • Form Fields (Table Order): 1. Full name (required, 2-60 chars, error: "Enter your full name.")
    2. Phone number (optional, +27 format, error: "Enter a South African number, like +27 82 123 4567.")
    3. Home ward (required for residents, error: "Choose your ward.")
    4. Language dropdown (required, BR18: English, Afrikaans, isiZulu, Sepedi).
  • Action Stack Order: Primary "Save changes" button → Link "Privacy Notice" (→ M7) → Secondary button "Log out" (→ S1) → Danger button "Delete account" (Residents only → M5).
  • Role-Based Tab Bar: Profile active with green badge / initials avatar. Resident 4-tab bar (Faults, Report, My reports, Profile) and Ward Admin 4-tab bar (Queue, Dashboard, Faults, Profile) fully demonstrated.
State Coverage & Business Rules Verification
  • State 1 (Normal): Pre-filled with Thandeka Mokoena's verified seed profile (Ward A: Orlando West, isiZulu).
  • State 2 (Success): Displays the verbatim toast notification: "Profile saved".
  • State 3 (Loading): Grey pulsing placeholder lines while profile loads + "Save changes" button displaying animated spinner with "Saving changes…".
  • State 4 (Error): Verbatim message "Something went wrong. Try again." + exact phone validation error, preserving all user edits in the form.
  • State 5 (Offline): Top charcoal grey banner "You're offline. Changes will not be saved." + disabled "Save changes" button.
  • Role Differences Handled: "Home ward" and "Delete account" are restricted to Residents. Staff view (Zanele Khumalo) demonstrates omitted/locked ward and system-managed staff deletion note.
  • Empty State: Explicitly marked as not needed per PRD Section 8.2.
✔ MISSING ITEMS & TODOS: All required elements, order, labels, states, and seed data were fully provided in PRD Section 8.2, 8.3, 8.4, and BR18. No TODO placeholder boxes were required.
